E-Commerce Product Price Predictor

An end-to-end supervised machine learning pipeline designed to predict continuous variables (product prices) 
from raw e-commerce catalog data. Built as a foundational architecture for algorithmic pricing models.

Problem Statement

Digital marketplaces process massive amounts of unstructured product metadata. This project addresses the challenge
of handling messy, real-world e-commerce datasets by converting unstructured text into predictive numerical features 
to accurately forecast market prices.

Dataset & Technical Approach

1)Automated Data Cleaning: Drops missing target labels, handles NaN ingestion, and deduplicates records based on unique 
matrix IDs.

2)Feature Engineering: Applies regular expressions to strip irregular characters and lowercase descriptions to unify 
vocabulary tokens. Utilizes Scikit-Learn's TfidfVectorizer to map raw text strings into a mathematical matrix.

3)Model Selection: Implements Ridge Regression (L2 Regularization) to process the high-dimensional sparse matrices 
generated by text vectorization without overfitting.

4)Evaluation: Validates algorithm accuracy using the Symmetric Mean Absolute Percentage Error (SMAPE) metric.

Tech Stack

1)Language: Python

2)Data Manipulation: Pandas, NumPy

3)Machine Learning: Scikit-Learn

How to Run

Follow these steps to set up the environment and run the pipeline locally:

1)Clone the repository:

Bash

git clone https://github.com/ItzJeston/ml-price-predictor.git

2)Navigate to the directory:

Bash

cd ml-price-predictor

3)Install required libraries:

Bash

pip install pandas numpy scikit-learn

4)Execute the pipeline:

Bash

python baseline_pipeline.py


Results & Output

The script automatically generates a local validation set to track model drift and outputs a final
predictions file. Current baseline performance on the mock dataset yields a Local Validation SMAPE 
Score of 13.56%. The final output is a properly formatted submission.csv containing the testing IDs
and predicted prices.
