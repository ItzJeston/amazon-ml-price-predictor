E-Commerce Product Price Predictor
An end-to-end supervised machine learning pipeline designed to predict continuous variables (product prices) from raw e-commerce catalog data. Built as a foundational architecture for algorithmic pricing models and data science hackathons.

Problem Statement
Digital marketplaces process massive amounts of unstructured product metadata. This project addresses the challenge of handling messy, real-world e-commerce datasets by converting unstructured text into predictive numerical features to accurately forecast market prices.

Dataset & Technical Approach
Automated Data Cleaning: Drops missing target labels, handles NaN ingestion, and deduplicates records based on unique matrix IDs.

Feature Engineering: Applies regular expressions to strip irregular characters and lowercase descriptions to unify vocabulary tokens. Utilizes Scikit-Learn's TfidfVectorizer to map raw text strings into a mathematical matrix.

Model Selection: Implements Ridge Regression (L2 Regularization) to process the high-dimensional sparse matrices generated by text vectorization without overfitting.

Evaluation: Validates algorithm accuracy using the Symmetric Mean Absolute Percentage Error (SMAPE) metric.

Tech Stack
Language: Python

Data Manipulation: Pandas, NumPy

Machine Learning: Scikit-Learn

How to Run
Follow these steps to set up the environment and run the pipeline locally:

Clone the repository: git clone [https://github.com/ItzJeston/amazon-ml-price-predictor.git](https://github.com/ItzJeston/amazon-ml-price-predictor.git)

Navigate to the directory: cd amazon-ml-price-predictor

Install required libraries: pip install pandas numpy scikit-learn

Execute the pipeline: python baseline_pipeline.py

Results & Output
The script automatically generates a local validation set to track model drift and outputs a final predictions file. Current baseline performance on the mock dataset yields a Local Validation SMAPE Score of 13.56%. The final output is a properly formatted submission.csv containing the testing IDs and predicted prices.
